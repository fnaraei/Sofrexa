# BASILIC POS

Restaurant management system for BASILIC Cafe & Restaurant — replaces the legacy ItKafe program.

- **Plan & roadmap (Persian):** [PLAN.md](PLAN.md) — tick boxes show what is done.
- **Design (Figma, source of truth):** https://www.figma.com/design/1VzYLeeic0ExwgdWt7RbVw
- **Architecture:** local-first. The cashier PC runs the in-house server; the web copy on the host syncs with it and receives QR and online orders.

Folders:

- `docs/screens.md` — index of all 73 screens with direct Figma links
- `docs/design-handoff.md` — tokens → CSS variables, components, layout rules for implementation
- `docs/figma-ids.json` — Figma page, component and variable-collection IDs
- `design/` — overview image of each Figma page
